긴 작업 도중 응답 없이 턴이 끝나자 사용자가 "너 멈춤", "다시 시도"라고 여러 번 다시 요청했다 (2026-09-29). 특히 앞에서 오래 기다리는(foreground) 하위 에이전트 호출 중에 세션이 끊겼다.

**Why:** 사용자는 화면에 보이는 글과 파일로만 진행 상황을 안다. 도구 호출만 하다가 끝나면 멈춘 것으로 보인다.

2026-10-20: 이 환경에서는 세션이 자주 끝나고, 그때마다 백그라운드 Workflow·에이전트가 결과 없이 죽는다(검토 워크플로 4번 연속 0건). 사용자가 "멈추고 토큰만 빤다"고 항의함. → 같은 백그라운드 작업을 반복 재실행하지 말 것. 짧은 전경(foreground) 작업으로 하고, 결과는 파일에 바로 남기고, 한 번 죽으면 사용자에게 먼저 알린 뒤 할지 묻는다.

2026-10-22: 세션이 자주 끝나 워크플로가 계속 죽음 (사용자 "멈춤", "??"). 긴 한 덩어리 작업(에이전트 하나가 코드를 오래 고치는 것)은 반쯤 고친 채로 죽어 손해 → 코드 고치기는 내가 앞에서(전경) 직접 하고, 워크플로는 결과를 항목마다 파일로 바로 남기는 일(브랜드별 스펙 읽기 등)에만 쓴다. 다시 켤 때는 이미 된 항목을 빼고 남은 것만.

2026-10-27: 그림 읽는 에이전트 6개를 한꺼번에 띄우자 1분 만에 세션이 죽음(에이전트 기록이 1분에 1~2MB씩 불어남). → 그림을 많이 읽는 워크플로는 3개 이하로 동시에.

**How to apply:** 도구 작업이 여러 단계로 이어질 때는 단계마다 한두 문장으로 무엇을 하는지 한국어로 적고, 결과물이 나오면 검증을 더 하기 전에 먼저 SendUserFile로 보내고 요약을 남긴다. 오래 걸리는 검증·에이전트는 백그라운드로 돌린다. 관련: [[sindo-catalog-project]]
